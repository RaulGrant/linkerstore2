# Imágenes de CENACAP

Coloca las imágenes de cursos en `courses/` usando los nombres definidos en `CoursesSection.tsx`.
Coloca las fotos de testimonios en `testimonials/` usando los nombres definidos en `TestimonialsSection.tsx`.

Mientras un archivo no exista o no cargue, la landing mostrará automáticamente el emoji correspondiente.
